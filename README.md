# Bitart Ambient

Cute retro **pixel-art ambient player** — peaceful screensavers with soft procedural soundscapes.

Scenes (Imagine-generated bitart):

| Scene | Mood |
|-------|------|
| Fireplace | Cozy cabin crackle |
| Rainforest | Waterfall & birds |
| Ocean | Sunset shore waves |
| Rainy Nite | Neon rain window |
| Starfield | Campfire under stars |
| Sakura | Cherry blossom garden |

## Features

- Retro player shell with **thocky** mechanical buttons
- Procedural Web Audio ambience (no audio files)
- Canvas particle FX (embers, rain, petals, fireflies…)
- Mobile-friendly: swipe scenes, large tap targets, safe areas
- Fullscreen / screensaver mode
- Keyboard: `Space` play, `←` `→` scenes, `F` fullscreen, `M` mute

## Local

Open `index.html` in a browser, or:

```bash
npx serve .
```
